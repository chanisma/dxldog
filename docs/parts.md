# 부품 선정과 BOM

조사일: 2026-10-11 (가격은 ROBOTIS US 스토어 기준). ⚠️ 표시는 확인되지 않은 값이다.

## 1. 모터 선정: 시뮬레이션으로 정했다
- 모델: SpotMicro 치수(`sim/dog_model.py`). 질량은 CAD로 계산한 프린트 부품 무게에 모터·배터리·전자부품을 더했다. XL 구성 1.71 kg, XM 구성 1.91 kg.
- 방법: 모터 최대 힘을 각 모터의 **정지 토크(12 V)**로 제한하고 동작을 시켰다. 성공 여부와 함께 **RMS 토크 ÷ 정지 토크**(평균 부하율)를 쟀다.
- 기준: 서보는 평균 부하가 정지 토크의 약 30–40 %를 넘으면 오래 쓸 때 과열되기 쉽다(일반적인 경험칙 ⚠️).

| 모터 | 정지 토크 @12 V | 1개 가격 | 서기 (무릎) | 보통 걸음 (무릎 / 엉덩이) | 빠른 걸음 | 판단 |
|---|---|---|---|---|---|---|
| XL430-W250 | 1.5 Nm | $27.50 | 26 % | 성공, 58 % / 54 % | 성공, 75 % / 74 % | 서기·자세는 충분. **오래 걸으면 과열 위험** |
| XC430-W240 | 1.9 Nm | $137.89 | 21 % | 성공, 47 % / 43 % | 성공, 61 % / 55 % | XL보다 5배 비싸고 27 %만 셈 → 비추천 |
| XM430-W210 | 3.0 Nm | $310.39 | 15 % | 성공, 31 % / 30 % | 성공, 41 % / 37 % | 괜찮음 (더 빠름: 77 rpm) |
| **XM430-W350** | 4.1 Nm | $310.39 | 11 % | 성공, 23 % / 22 % | 성공, 30 % / 28 % | **여유 있음** |

추가로 확인한 것:
- **옆으로 벌리기(hip_x) 관절은 부하가 작다.** 평균 0.15–0.3 Nm라 XL430으로 충분하다. 그래서 권장 구성은 이 4개만 XL430으로 한다.
- **로봇을 80–90 % 크기로 줄여도** 걸을 때 XL430 부하는 40–55 %다. 걷는 동안의 부하는 몸무게보다 다리를 움직이는 동작에서 주로 오므로, 크게 줄지 않는다. 그래서 SpotMicro 원래 크기를 유지했다(`sim/scale_study.py`).
- 걸음새를 느리게 하면 부하가 줄어든다. XL430 기준: 빠름 69 % → 보통 61 % → 느림 51 % (`sim/gait_sweep.py`, CAD 반영 전 질량).
- 참고 논문(Open Ant, arXiv 2607.18488, 요약만 확인 ⚠️): 0.98 kg 로봇에서 XL430은 힘이 부족했고 XM430-W350은 충분했다고 보고했다.

## 3. 배선
- DYNAMIXEL TTL(3핀)을 줄줄이 잇는다(데이지 체인). 한 줄에 서보 3개 이하로 나누면 전류와 고장 위치를 관리하기 쉽다(커뮤니티 권장 ⚠️). 다리 하나를 한 줄로 하면 4줄 → Power Hub에서 나눈다.
- ID 배정 예시: FL 1·2·3, FR 4·5·6, RL 7·8·9, RR 10·11·12 (hip_x, hip_y, knee 순). 통신 속도 1 Mbps.

## 4. 전원 주의
- XL430: 6.5–12 V (권장 11.1 V). XM430: 10–14.8 V (권장 12 V). **섞어 쓸 때는 12 V 고정 전원**이 둘 다의 범위 안이다.
- 3S LiPo는 완충하면 12.6 V로 XL430 최대치를 넘는다(펌웨어 한계 14 V라 멈추지는 않지만 규격 밖이다). 배터리를 쓰려면 12 V 강압 레귤레이터를 넣는다 ⚠️ 대전류 레귤레이터를 따로 골라야 함.
