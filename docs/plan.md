# DXL Dog 프로젝트 기획서 — SpotMicro × ROBOTIS DYNAMIXEL

작성일: 2026-10-12

## 1. 목표
- 오픈소스 4족 로봇 **SpotMicro**(CC BY 4.0)의 크기와 다리 구조를 따르고, 모터를 **ROBOTIS DYNAMIXEL X430**으로 바꾼 교육용 로봇개 **DXL Dog**를 만든다.
- robotdog(Lite3) 과정의 심화 실습 J1–J5(모터 하나 → 자세 → 기구학 → 무게중심 → 걸음새)를 **학생이 직접 만든 실물 로봇**으로 이어 간다.
- 같은 코드가 시뮬레이터와 실물에서 돌도록 한다. Lite3 Studio의 `JointDog`와 같은 모양의 `Dog` API를 만들고 DYNAMIXEL 백엔드를 붙인다 ([software.md](software.md)).

## 3. 정한 것 (2026-10-12)
- **권장 구성**(hip_x XL430 × 4 + hip_y·knee XM430-W350 × 8)으로 **1대**를 먼저 만든다.
- 두뇌는 **둘 다** 지원한다: 노트북 + U2D2 케이블로 시작하고, 최종적으로 **Raspberry Pi를 몸에 싣는다** ([rpi_setup.md](rpi_setup.md)). 학생 코드는 같다.
- 시뮬레이터도 같은 코드로 돈다 (CAD 모양·질량 반영).
- 가지고 있는 LeRobot 모터(Feetech STS3215 12 V)로 만드는 **STS 버전**도 지원한다 ([sts.md](sts.md)). 시뮬레이션상 힘은 충분하다(걷기 평균 부하 23 % 이하).

### 처음에 비교했던 선택지
1. **모터 등급** (예산과 사용 방식에 따라, 근거는 [`parts.md`](parts.md))

   | 등급 | 구성 | 모터 값 | 맞는 사용 |
   |---|---|---|---|
   | 입문 | XL430 × 12 | 약 $330 | 서기·자세·짧은 걷기 시연. 오래 걸으면 과열 위험 |
   | **권장** | 옆 관절 XL430 × 4 + 앞뒤·무릎 XM430-W350 × 8 | 약 $2,590 | 수업에서 반복해서 걷기, 걸음새 실험 |
   | 여유 | XM430-W350 × 12 | 약 $3,720 | 연구용 (강화학습 실물 적용 등) |

2. **대수**: 반 전체에 1대(시연 + 조별 순환) 또는 조별 1대(입문 등급)
3. **두뇌**: 노트북 유선 연결(U2D2)로 시작할지, 처음부터 Raspberry Pi를 몸에 실을지

## 4. 단계별 일정 (예시)
| 단계 | 기간 | 할 일 | 끝났다는 기준 |
|---|---|---|---|
| 0. 확인 | 1주 | 모터 1개 + U2D2 + 전원만 먼저 구매 → 맞춤 시험 부품 3개 인쇄 (30분) → 혼 구멍·옆면 구멍·몸통 틈 확인 → 필요하면 `cad/x430.py` 수정 | 시험 부품이 나사 구멍과 맞음 |
| 1. 다리 하나 | 1–2주 | 어깨·허벅지·정강이·발 인쇄 + 모터 3개 → 다리를 책상에 고정해 관절 범위·강도·나사 확인 | 다리가 범위 안에서 걸리지 않고 움직임 |
| 2. 전체 조립 | 2주 | 몸통 판·기둥, 모터 12개 ID 설정(`tools setup`), 배선, 전원, 영점 보정(`tools calibrate`) | `tools scan`에서 12개 모두 응답 |
| 3. 소프트웨어 | 1–2주 | ✅ 코드는 준비됨. 실물에서 `tools check` → J1–J5를 `--real`로 실행하며 값 조정 | 시뮬과 같은 코드로 실물이 섬·걸음 |
| 3+. Raspberry Pi | 1주 | Pi·5 V 강압 변환기 장착, [rpi_setup.md](rpi_setup.md) 순서대로 설치, 스튜디오를 Pi에서 실행 | 케이블 없이 노트북 브라우저로 조종 |
| 4. 수업 적용 | 학기 | 조립 실습, 관절·기구학, 걸음새 조정, 온도·전류 측정 실험 | 차시 운영 |

## 5. 교육 과정 연결
| robotdog 시뮬 (Lite3) | DXL Dog 실물 | 새로 배우는 것 |
|---|---|---|
| J1 모터 하나 | 서보 ID·통신·목표 위치 | 버스 통신, 모터 설정(ID, 통신 속도, 위치 범위) |
| J2 자세 | 엎드리기·서기·앉기 | 실제 모터의 속도·가속 제한 (Profile Velocity) |
| J3 기구학 | 같은 IK, 링크 길이만 SpotMicro 값으로 | 치수 측정과 보정 |
| J4 무게중심 | 다리 들기 (8 관절이면 불가, 12 관절이라 가능) | 실제 무게 측정, 배터리 위치의 영향 |
| J5 트롯 | 걸음새 + **모터 온도 관찰** | 모터 부하와 열 (시뮬 RMS 토크 비율과 비교) |

## 6. 위험과 대응
| 위험 | 대응 |
|---|---|
| XL430 과열 (걸을 때 평균 부하가 정지 토크의 58–75 %) | 권장 등급 선택. 또는 걷기를 짧게 하고 `Present Temperature`를 계속 보면서 하드웨어 보호 설정 사용 |
| 도면에 없는 치수 (혼 높이, 아이들러 두께) | 0단계 맞춤 시험. 값은 `cad/x430.py` 한 곳에서 고침 |
| 인쇄 부품 강도 (포크 팔 4 mm) | PETG 권장, 벽 4줄 이상, 채움 30–40 %. 1단계 다리 시험에서 확인 |
| 무릎 접힘 한계 125° | 완전히 배를 대고 눕지는 못함 (쉬는 자세 몸 높이 약 13 cm). 설계상 의도된 한계 |
| 배선 경로 미설계 | v0.1에는 케이블 고정 구멍이 없음 → 1단계에서 경로를 정하고 CAD에 반영 |
| 3S LiPo 완충 전압 12.6 V > XL430 최대 12 V | 12 V 고정 전원으로 시작. 배터리를 쓸 때는 XM430 전용 구성이나 강압 레귤레이터 사용 |
